    How the full detector works

    Three encoders, one fused verdict

    Each modality is encoded by a pretrained transformer into a single token. A fusion transformer attends over the tokens behind a learned [CLS] token and two heads predict phishing and deepfake. A missing modality, like an email with no audio, is masked out of the attention instead of being filled with fake zeros.

    Run it yourself

    From smoke test to robustness report

    Train

    python -m src.train \
  --train_manifest data/train.csv \
  --val_manifest data/val.csv

    Best checkpoint and history go to outputs/run/. Add --tiny for a no-download smoke test.

    Attack it

    python -m src.robustness \
  --manifest data/test.csv \
  --space vision \
  --epsilons 0 0.01 0.03 0.1

    Evasion rate: of the fakes the model caught, how many an attacker flips to "real".

    Score samples

    python -m src.inference \
  --text "URGENT: verify..." \
  --audio memo.wav

    Writes probabilities and red flags to outputs/predictions.csv.

    The deepfake model needs training on labelled data (FaceForensics++, ASVspoof, a phishing email corpus) before its scores mean anything; this page only runs the rule-based analyzer. Built as a student cyber security project.
