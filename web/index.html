Deepfake Phishing Detector

A toolkit for spotting social engineering: red flags in phishing messages and links, spoofing checks on email headers, and fake news claims checked against published fact-checks. The red-flag analyzers run in your browser; only the fact-check lookup sends your claim to a server.

Source on GitHub Project report Threat model

Same rules as python -m cyber message. For a full email with headers (SPF, DKIM, DMARC, Reply-To, spoofed display names), use python -m cyber email file.eml.

      Optional extension: deepfake detection with ML

      Three encoders, one fused verdict

      Not needed to use the toolkit. For deepfake voices and images the repo includes an optional ML model in ml/. Each modality is encoded by a pretrained transformer into a single token. A fusion transformer attends over the tokens behind a learned [CLS] token and two heads predict phishing and deepfake. A missing modality, like an email with no audio, is masked out of the attention instead of being filled with fake zeros.

      Run it yourself

      Three commands, no setup

      Check an email

      python -m cyber email suspicious.eml

      SPF, DKIM, DMARC, Reply-To and Return-Path mismatches, spoofed display names, links that lie about where they go.

      Check a message

      python -m cyber message \
  "URGENT: verify at http://192.168.4.1"

      The same phishing red flags as the analyzer above.

      Check a news claim

      export FACTCHECK_API_KEY=...
python -m cyber news "5G spreads viruses"

      Fake news red flags, plus published fact-checks.

      Python 3 only, no installs needed for the cyber tools. The optional deepfake ML model in ml/ needs training on labelled data before its scores mean anything. Built as a student cyber security project.
